The input file for the project is added to the repository.
The user needs to upload it to the runtime environment. 
The user needs to run the python notebook .ipynb file, or the python file .py file. 
The user should provide the value of n.
Viola! Groups will be formed in the respective directories.
The user can check the groups according to the three techniques of full branchwise, mixed and uniform groups.
The user can also refer to the stats file in the respective folders.
